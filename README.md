# 稳步

一个移动端优先的三大项力量训练周期记录网站。用户数据仅保存在当前浏览器中，不需要账号或服务器。

## 功能

- 根据深蹲、卧推、硬拉当前 1RM 自动生成周期计划
- 支持每项每周一次或主练加轻练两次
- 逐组记录完成或未完成，并提供失败调整建议
- 组间倒计时、声音、震动和浏览器通知
- 周期进度、历史训练和三大项目标
- JSON 数据导出与导入

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建与测试：

```bash
pnpm test
pnpm build
```

## 发布到 GitHub Pages

1. 将项目推送到 GitHub 仓库的 `main` 分支。
2. 在仓库设置中打开 `Pages`。
3. 将来源选择为 `GitHub Actions`。
4. 推送代码后，项目内的工作流会自动测试、构建并发布。

浏览器普通网页在 iPhone 后台运行时，声音和震动可能受系统限制；倒计时本身使用时间戳计算，返回页面后仍会保持准确。
